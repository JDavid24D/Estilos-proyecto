Sobre qué trata el proyecto

NETTPLUS registra la asistencia de sus colaboradores en Z-biotime (ZKTeco), pero el sistema no entrega los resúmenes que Recursos Humanos necesita. En este proyecto vamos a construir una aplicación web tipo dashboard que tome esos datos, calcule horas trabajadas, atrasos y ausentismos, muestre un resumen diario por colaborador, guarde un historial y genere de forma automática el reporte mensual para la nómina.
